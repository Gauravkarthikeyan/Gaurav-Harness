terminal background; themes declare `terminal.background = paneBg`.

## 2. Typography & glyphs
- Status: `✓` done · `●` running (accent) · `○` queued/waiting · `◆` skill · `▸` thinking/note · `!` warning/needs-auth · `✗` failed · `❯` user prompt / composer.
- Box drawing: light `┌─┐│└┘` for panes and inner cards; focused pane uses the same glyphs in `borderFocus`
  (wireframes draw it heavy `┏━┓┃┗┛` only to mark focus). Bars: `▕ ▁…█ ▏`; sparklines `▁▂▃▄▅▆▇█`.
- Bold only for: pane titles' index (`0.1`), the active tab, headline values (RUN $, clock). Never bold whole lines.
- Logo: pixel wordmark "GAURAV'S HARNESS" (`packages/tui/src/gk/pixel-font.ts`, 5-row half-block glyphs, shadow in
  `pixelShadow` ½ row down and 1 col right). Scale 2 = 153×6 (splash, picker). The header (≥ 180 cols) uses scale 1 with
  a straight drop shadow (½ row down only, so the 1-col letter gaps stay clear) = 76×3, `</>` badge mark left of it.
  Below 180 cols the header uses bold accent text `</>  G A U R A V ' S   H A R N E S S` (unspaced below 110 cols).

## 3. Chrome (212×58 reference)
- Header bar (rows 0–2, `paneBg`; labels `muted`, values `text`): `</>` badge + scale-1 logo; field columns SESSION/MODE/HOST · CWD/BRANCH/UPTIME ·
  RUN (cost / budget bar %)/SAVED/CTX (bar, used/limit) · clock/date/TODAY right-aligned. 110–179 cols: 2 text rows. < 110: 1 row.
- Tab row (row 3): tmux windows `0:stage* 1:crew 2:logs 3:git 4:pty:claude`; right: run counts `● 2 running ○ 1 queued ✓ 1 done │ plan#1 · 4 items`.
- Pane frame: title left `<win>.<pane> <name> · <detail>`, badge right (`@agent` in its hue on `badgeBg`, or `● pid · elapsed`),
  footer statusline inside the pane: `agent │ ⎇ branch │ ✱ model │ § tokens │ $cost │ ◔ ctx (%) │ scope`; composer pane adds a mode line.
- Status bar (row H-2, `panel`): `[gk] 0:stage*  ⎇ main ↑2  MCP 3/4 · skills 19` … `✱ model role │ crew 2▸ 1○ 1✓ │ $run │ HH:MM date`.
- Key-hint bar (row H-1): `^K palette  ⏎ zoom pane  ^O expand  M-a agent hub  ^] release pty  ? help` … `gk-code 0.1.0` (no upstream version string).

## 5. Launch screens (implemented: `packages/tui/src/gk/splash-frame.ts`, `mode-picker.ts`, `launch-screens.ts`; flow `packages/coding-agent/src/gk/launch.ts`)
Both screens paint every cell `paneBg` (black) and share the lockup (`packages/tui/src/gk/logo.ts`): `</>` badge
(`dim` box, `accent` glyphs) 2 cols left of the pixel wordmark, scale 2 when ≥ 164 cols, scale 1 with badge when
≥ 88, scale 1 bare when ≥ 79, else the text `</> GAURAV'S HARNESS`. Gold appears only on the wordmark, the lit cap of
the globe and its satellite, a running check's spinner, the filled bar, the focused card and the key hints.

### 5.1 Splash
- When: every interactive TTY launch of a fresh session (`startup.showSplash`, default `true`; off for `--print`,
  RPC/ACP, resume/continue/fork, `startup.quiet`, `PI_TIMING`, non-TTY). Not shown while the setup wizard runs.
- Timing: the motion runs ≥ 3.5 s. Check rows settle on screen one by one, evenly between 0.5 s and 2.5 s (or later,
  when the check itself does), then the finished checklist and full bar hold 1 s before the picker; hard cap 6 s. Any key
  skips (mouse and focus reports do not), Ctrl+C quits. `tui.motion` reduced/none: fixed globe angle, `●` instead of
  the spinner, real check states at once, shown until the checks settle (≥ 0.5 s, ≤ 6 s).
- Globe: dot wireframe (5 latitude rings + 12 meridians) rotating about its vertical axis at 0.9 rad/s, tilted
  0.38 rad toward the viewer, orthographic projection, 2:1 cell aspect, z-buffered per cell. Shade = 0.55·depth +
  0.45·Lambert (key light upper left): `·` dim → `·` muted → `•` muted → `•` accent (lit front cap only). The far
  hemisphere is thinned to every other sample. One inclined orbit ring (r 1.45, hidden behind the globe) and an
  `accentStrong` `●` satellite. Height ≈ 42 % of the screen, whatever is left after the fixed blocks.
- Checklist (centered, ≤ 76 cols): `glyph label(14) value(18) detail`. Checks run in parallel with the animation,
  from the real sources: providers = distinct providers among `ModelRegistry.getAvailable()` after the initial model
  refresh; roster = enabled `buildRoster(availableRosterModels(), ~/.gk/agent/roster.yml)` with a tier summary;
  skills = the session's loaded skills; mcp = connected / known servers after `waitForPendingConnections()`;
  computer use = `computer.enabled` on a supported platform. States: `✓` ok (`success`), spinner/`●` probing
  (`accent`), `!` warn (`warning`, e.g. MCP 3/4, 0 providers), `○` off (`dim`), `✗` failed (`error`).
  Checks still pending at the cap stay pending on the last frame and are aborted.
- Bar: `━` accent for the settled share, `─` `border` for the rest, then `n/m` muted.
- Top row (dim): `gk-code boot · <platform> <arch> · pid <pid>` left, `<cols>×<rows>` right.
- Footer (dim): `by Gaurav Karthikeyan · github.com/Gauravkarthikeyan` left, `gk-code 0.1.0 · any key to skip` right;
  stacked on two rows when one row cannot hold both.

### 5.2 Mode picker
- When: `gk.launchMode: ask` (default) on a launch that may ask (interactive TTY, fresh session). `gk.launchMode:
  solo|orchestra` or `--solo` / `--orchestra` skip it (the flags win; both at once is a usage error). It opens in the
  splash's overlay right after the splash, or alone when the splash is off; after the setup wizard when that runs.
- Cards: `Solo` and `Orchestra`, ≤ 56 cols each, 3 cols apart. Title in the top edge, `· last used` on the
  previous choice (`gk.lastLaunchMode`, preselected), hotkey right (`s` / `o`). Focused card: `borderFocus` frame,
  `accent` title, `text` body; the other card `border` frame, `muted` title and body. Body: one factual sentence,
  then live facts. Solo: `model` (session default), `tools` (skills · MCP n/m), `cwd`. Orchestra: `conductor`
  (`modelRoles.conductor`, else the default model), `roster` (enabled models · tier summary), and while Orchestra
  is not wired into the launch flow `status ! not wired yet · starts Solo` in `warning`.
- Keys: ←/→ (or h/l, Tab) focus, Enter starts the focused card, `s` / `o` start that card, Ctrl+C quits. The choice
  is saved to `gk.lastLaunchMode`. Choosing Orchestra before its entry exists starts Solo with the notice
  `! Orchestra mode is not wired yet`.
- Author line (dim, centered) at H-3; key-hint bar at H-1 on `panel`: keys `accent`, labels `muted`, `gk-code 0.1.0`
  right.
