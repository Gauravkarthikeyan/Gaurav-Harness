terminal background; themes declare `terminal.background = paneBg`.

## 2. Typography & glyphs
- Status: `✓` done · `●` running (accent) · `○` queued/waiting · `◆` skill · `▸` thinking/note · `!` warning/needs-auth · `✗` failed · `❯` user prompt / composer.
- Box drawing: light `┌─┐│└┘` for panes and inner cards; focused pane uses the same glyphs in `borderFocus`
  (wireframes draw it heavy `┏━┓┃┗┛` only to mark focus). Bars: `▕ ▁…█ ▏`; sparklines `▁▂▃▄▅▆▇█`.
- Bold only for: pane titles' index (`0.1`), the active tab, headline values (RUN $, clock). Never bold whole lines.
- Logo: pixel wordmark "GAURAV'S HARNESS" (`packages/tui/src/gk/pixel-font.ts`, 5-row half-block glyphs, shadow in
  `pixelShadow` 1 col right / ½ row down). Scale 1 = 77×3 cells (header ≥ 180 cols), scale 2 = 153×6 (splash, picker).
  `</>` badge mark left of it. Below 180 cols the header uses text `</> GAURAV'S HARNESS` in accent.

## 3. Chrome (212×58 reference)
- Header bar (rows 0–2, `panel`): `</>` badge + scale-1 logo; field columns SESSION/MODE/HOST · CWD/BRANCH/UPTIME ·
  RUN (cost / budget bar %)/SAVED/CTX (bar, used/limit) · clock/date/TODAY right-aligned. 110–179 cols: 2 text rows. < 110: 1 row.
- Tab row (row 3): tmux windows `0:stage* 1:crew 2:logs 3:git 4:pty:claude`; right: run counts `● 2 running ○ 1 queued ✓ 1 done │ plan#1 · 4 items`.
- Pane frame: title left `<win>.<pane> <name> · <detail>`, badge right (`@agent` in its hue on `badgeBg`, or `● pid · elapsed`),
  footer statusline inside the pane: `agent │ ⎇ branch │ ✱ model │ § tokens │ $cost │ ◔ ctx (%) │ scope`; composer pane adds a mode line.
- Status bar (row H-2, `panel`): `[gk] 0:stage*  ⎇ main ↑2  MCP 3/4 · skills 19` … `✱ model role │ crew 2▸ 1○ 1✓ │ $run │ HH:MM date`.
- Key-hint bar (row H-1): `^K palette  ⏎ zoom pane  ^O expand  M-a agent hub  ^] release pty  ? help` … `gk-code 0.1.0` (no upstream version string).
